# Fotos de referencia del catálogo

Cada producto de la lista por defecto (`CatalogoInicializador.LISTA_POR_DEFECTO`) usa como foto de referencia
`/images/productos/{slug}.webp`. Estas fotos solo se muestran cuando una oferta no tiene foto propia.

## Especificaciones

- Formato: **WebP**
- Tamaño: **800×800 px** (cuadrada)
- Peso: **≤ 100 KB**
- Nombre: slug del producto = minúsculas, sin tildes (ñ → n), caracteres no alfanuméricos → guion. Ej.: `Mango de azúcar` → `mango-de-azucar.webp`
